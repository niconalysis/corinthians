# Identidade da partida vem da fonte, não da posição no ano

A base legada identificava a partida por "número no ano + ano" (72026 = 7ª partida de 2026). Esse ID muda quando uma partida antiga é incluída depois (renumerando o resto do ano) e confunde ano-calendário com temporada (a temporada 2020 terminou em 2021). Passamos a usar o ID do evento na fonte como identidade. O número da partida no ano continua existindo como atributo de exibição.
